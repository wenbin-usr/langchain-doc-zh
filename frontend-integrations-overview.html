集成概览

将 useStream 连接到任意 React UI 组件库或生成式 UI 框架
约 2 分钟 社区翻译 查看英文原文 ↗

useStream 与 UI 无关。它返回普通的响应式状态，其中包含消息、工具调用、加载标志、值和线程元数据，你可以将这些接入任意选定的视觉层。这些页面展示不同库如何与 LangChain 前端集成，每个库在构建 AI 对话和生成式 UI 方面都有各自的理念。

集成#

CopilotKit

完整的 AI 对话运行时，支持结构化生成式 UI。向你的 LangGraph 部署添加自定义 CopilotKit 端点，然后在 React 中渲染动态组件树。

AI Elements

基于 shadcn/ui 的可组合组件，用于 AI 对话。直接引入 Conversation、Message、Tool 和 Reasoning，并将它们直接接入 stream.messages。

assistant-ui

无头 React 框架，带有完整的运行时层。useStream 与 AssistantRuntimeProvider 之间的桥接由 useExternalStoreRuntime 适配器完成。

OpenUI

生成式 UI 库，让智能体以声明式组件 DSL 生成完整的交互式仪表盘。专为数据丰富、报告风格的 UI 而构建。

如何选择库#

每个库适用的集成模式略有不同。选择取决于你正在构建的 UI 类型：

CopilotKitAI Elementsassistant-uiOpenUI
最适合完整的对话运行时加结构化生成式 UI支持丰富消息类型的对话配置极少、功能完整的对话生成的仪表盘和报告
UI 风格CopilotKit 对话外壳 + 自定义消息渲染器可组合的 shadcn/ui 组件无头插槽 + 默认主题内置组件库，搭配声明式 DSL
自定义方式自定义后端端点、智能体上下文和渲染器直接编辑源文件覆盖组件插槽通过 CSS 自定义属性设置主题
流式传输体验由运行时管理的对话流，携带结构化的助手负载组件级渐进式渲染内置线程管理提升渲染：外壳立即出现，数据随后填充
工具调用通过 CopilotKit 运行时和自定义渲染器Tool / ToolHeader / ToolOutput通过消息插槽自定义内嵌在生成的 UI 中
智能体格式结构化助手响应，可选支持 Markdown任意 stream.messages任意 stream.messages智能体输出 openui-lang 文本

这四个库都能与 LangChain 智能体良好配合，后三个还可以直接连接到 useStream。当你需要更丰富的运行时层，以及与 LangGraph 部署并存的专用端点时，CopilotKit 尤其有用。
