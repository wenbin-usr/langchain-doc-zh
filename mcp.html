MCP 概述

使用 MCPAdapter 将 LangChain 智能体连接到 MCP 服务器。
约 4 分钟 社区翻译 查看英文原文 ↗

Model Context Protocol (MCP) 是一个开放协议，用于标准化应用向语言模型提供工具和上下文的方式。LangChain 智能体通过 MCPAdapter 调用 MCP 服务器上定义的工具，后者会发现服务器的工具并将其适配为可直接传给 create_agent 的 LangChain 工具。

MCPAdapter 构建在 FastMCP 之上，由后者负责传输方式推断、协议协商、连接管理和身份验证。本节介绍 LangChain 特有的这一层，底层的连接细节则链接到 FastMCP 客户端文档。

注意

langchain.mcp 命名空间需要 langchain[mcp]>=1.4.0，目前处于 beta 阶段。从中导入会在每个进程中引发一次 LangChainBetaWarning。该 API 可能发生变化。

如果你在 v1.4.0 之前使用过 MCP，请参阅 从 langchain-mcp-adapters 迁移。

安装#

使用 mcp extra 安装 LangChain，它会一并引入 FastMCP：

pip install "langchain[mcp]"
uv add "langchain[mcp]"

快速开始#

打开 MCPAdapter，用 list_tools() 发现服务器的工具，并在上下文内构建智能体。这些工具持有客户端，因此上下文退出后智能体仍然可用：

python 
from langchain.agents import create_agent
from langchain.mcp import MCPAdapter


async def main():
    async with MCPAdapter("https://example.com/mcp") as adapter:
        tools = await adapter.list_tools()
        agent = create_agent("claude-sonnet-5", tools)
        return await agent.ainvoke({"messages": [{"role": "user", "content": "..."}]})

LangChain 文档 MCP 服务器

LangChain 文档 MCP 服务器 是一个公开的 HTTP 端点，地址为 https://docs.langchain.com/mcp。

将智能体连接到它，即可搜索和阅读文档，无需编写自定义工具：

python 
from langchain.agents import create_agent
from langchain.mcp import MCPAdapter


async def main():
    async with MCPAdapter("https://docs.langchain.com/mcp") as adapter:
        tools = await adapter.list_tools()
        agent = create_agent("claude-sonnet-5", tools)
        return await agent.ainvoke(
            {
                "messages": [
                    {
                        "role": "user",
                        "content": "How do I add short-term memory to a LangChain agent?",
                    }
                ]
            }
        )
注意

该文档 MCP 服务器是公开的，不需要 API 密钥。有关 IDE 和编程智能体的配置（Claude Code、Cursor 等），请参阅 以编程方式使用文档。

该服务器提供以下工具：

工具描述
search_docs_by_lang_chain搜索文档中的相关指南、操作方法和示例。
query_docs_filesystem_docs_by_lang_chain通过虚拟文件系统（rg、head、cat 及相关命令）读取或搜索文档。
submit_feedback报告文档页面的问题。

传输方式#

MCPAdapter 会根据你提供的目标推断传输方式。进程内服务器、通过 stdio 的本地脚本和远程 URL 之间，唯一的区别就是目标：

python 
from pathlib import Path

from langchain.mcp import MCPAdapter

# An in-process FastMCP server: no subprocess, no socket. Ideal for tests.
in_memory = MCPAdapter(server)  # a FastMCP instance

# A script path is launched over stdio, one subprocess per adapter.
stdio = MCPAdapter(Path("weather_server.py"))

# A string must be an http(s) URL, reached over streamable HTTP.
http = MCPAdapter("https://example.com/mcp")

目标可以是以下任意一种：

  • 一个 http / https URL（str）：通过 Streamable HTTP 访问。

  • 脚本路径（Path）：作为子进程通过 stdio 启动。

  • 传输对象（StreamableTransport）：预先配置好的传输对象。参见 客户端传输。

  • 进程内的 FastMCP 服务器：在内存中连接，无需子进程或套接字。

  • 一个 MCPConfig 字典（{"mcpServers": {...}}）：在一个适配器后面接入多个服务器。参见 连接。

  • 预先构建的 fastmcp.Client：可完全控制传输方式、缓存和 协议协商。

警告

str 目标必须是 http 或 https URL。FastMCP 解析字符串时，会先将其作为文件系统路径测试，然后才作为 URL 测试，因此一个指向已存在 .py 或 .js 文件的字符串会被当作子进程启动。由于目标最常以字符串形式来自配置或模型，MCPAdapter 会拒绝不符合 URL 形态的字符串。
