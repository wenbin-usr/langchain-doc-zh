时间旅行

查看、导航并从对话历史中的任意检查点恢复
约 7 分钟 社区翻译 查看英文原文 ↗

一个 检查点 是 LangGraph 智能体状态的已保存快照。时间旅行让你可以查看检查点，并从该已保存状态继续执行，以探索其他路径。

注意

此功能需要 LangGraph Agent Server。在本地用 langgraph dev 运行智能体，或 将其部署到 LangSmith以使用此模式。

检查点的工作方式#

LangGraph 在超级步边界处持久化智能体状态。同一超级步中并行运行的节点共享同一个检查点边界。每个持久化的状态都是一个 ThreadState 对象，它记录了以下内容：

  • checkpoint：检查点标识符，包括其 ID 和命名空间。

  • created_at：快照的创建时间。

  • parent_checkpoint：此路径中的上一个检查点。

  • values：该时间点的完整智能体状态（消息、自定义键）。

  • tasks：接下来被调度运行的图节点。

  • next：执行计划中即将运行的节点名称。

历史记录可能包含多条执行路径，而非一条线性的对话。getHistory() 按从新到旧的顺序返回检查点，默认上限为 10。请使用 parent_checkpoint 沿祖先关系追溯，而不要把相邻条目当作父与子。下面的示例展示了返回的那一页历史记录。

设置 useStream#

为智能体创建流，然后通过 LangGraph 客户端显式获取当前线程的检查点历史记录。从检查点恢复使用 forkFrom: checkpointId。

注意

代码示例使用 useStream<typeof myAgent> 来实现类型安全的流状态。有关 Python 或 JavaScript 后端的类型推断，请参阅 Type inference。

React 
import { useStream } from "@langchain/react";
import { useEffect, useState } from "react";

const AGENT_URL = "http://localhost:2024";

export function TimeTravelChat() {
  const [threadId, setThreadId] = useState<string | null>(null);
  const [history, setHistory] = useState<ThreadState[]>([]);
  const stream = useStream<typeof myAgent>({
    apiUrl: AGENT_URL,
    assistantId: "time_travel",
    threadId,
    onThreadId: setThreadId,
  });

  useEffect(() => {
    if (!threadId || stream.isLoading) return;
    stream.client.threads.getHistory(threadId).then(setHistory);
  }, [stream.client, threadId, stream.isLoading]);

  function resumeFrom(cp: ThreadState) {
    if (!cp.checkpoint.checkpoint_id) return;
    stream.submit(undefined, {
      forkFrom: cp.checkpoint.checkpoint_id,
    });
  }

  return (
    <div className="flex h-screen">
      <ChatPanel messages={stream.messages} />
      <TimelineSidebar history={history} onSelect={resumeFrom} />
    </div>
  );
}
Vue 
<script setup lang="ts">
import { useStream } from "@langchain/vue";
import { ref, watch } from "vue";

const AGENT_URL = "http://localhost:2024";
const threadId = ref<string | null>(null);
const history = ref<ThreadState[]>([]);

const stream = useStream<typeof myAgent>({
  apiUrl: AGENT_URL,
  assistantId: "time_travel",
  threadId,
  onThreadId: (id) => (threadId.value = id),
});

watch(
  [threadId, stream.isLoading],
  async ([id, isLoading]) => {
    if (isLoading) return;
    history.value = id
      ? ((await stream.client.threads.getHistory(id)) as ThreadState[])
      : [];
  },
  { immediate: true },
);

function resumeFrom(cp: ThreadState) {
  if (!cp.checkpoint.checkpoint_id) return;
  stream.submit(undefined, {
    forkFrom: cp.checkpoint.checkpoint_id,
  });
}
</script>

<template>
  <div class="flex h-screen">
    <ChatPanel :messages="stream.messages.value" />
    <TimelineSidebar :history="history" @select="resumeFrom" />
  </div>
</template>
Svelte 
<script lang="ts">
  import { useStream } from "@langchain/svelte";

  const AGENT_URL = "http://localhost:2024";
  let threadId = $state<string | null>(null);
  let history = $state<ThreadState[]>([]);

  const stream = useStream<typeof myAgent>({
    apiUrl: AGENT_URL,
    assistantId: "time_travel",
    threadId: () => threadId,
    onThreadId: (id) => (threadId = id),
  });

  $effect(() => {
    if (!threadId) {
      history = [];
      return;
    }
    if (stream.isLoading) return;
    stream.client.threads.getHistory(threadId).then((states) => {
      history = states as ThreadState[];
    });
  });

  function resumeFrom(cp: ThreadState) {
    if (!cp.checkpoint.checkpoint_id) return;
    stream.submit(undefined, {
      forkFrom: cp.checkpoint.checkpoint_id,
    });
  }
</script>

<div class="flex h-screen">
  <ChatPanel messages={stream.messages} />
  <TimelineSidebar {history} onSelect={resumeFrom} />
</div>
Angular 
import { Component, effect, signal } from "@angular/core";
import { injectStream } from "@langchain/angular";

const AGENT_URL = "http://localhost:2024";

@Component({
  selector: "app-time-travel-chat",
  template: `
    <div class="flex h-screen">
      <app-chat-panel [messages]="stream.messages()" />
      <app-timeline-sidebar
        [history]="history()"
        (select)="resumeFrom($event)"
      />
    </div>
  `,
})
export class TimeTravelChatComponent {
  threadId = signal<string | null>(null);
  history = signal<ThreadState[]>([]);

  stream = injectStream<typeof myAgent>({
    apiUrl: AGENT_URL,
    assistantId: "time_travel",
    threadId: this.threadId,
    onThreadId: (id) => this.threadId.set(id),
  });

  constructor() {
    effect(() => {
      if (this.stream.isLoading()) return;
      void this.refreshHistory(this.threadId());
    });
  }

  async refreshHistory(id: string | null) {
    this.history.set(id
      ? ((await this.stream.client.threads.getHistory(id)) as ThreadState[])
      : []);
  }

  resumeFrom(cp: ThreadState) {
    if (!cp.checkpoint.checkpoint_id) return;
    this.stream.submit(undefined, {
      forkFrom: cp.checkpoint.checkpoint_id,
    });
  }
}

构建检查点时间线#

时间线侧边栏将每个检查点显示为可点击的条目。每个条目展示已调度的节点以及该时间点已有的消息数量。tasks 描述的是下一步的工作，而非产生该检查点的节点。使用 next 标注所有已调度的节点，包括并行工作：

tsx 
function TimelineSidebar({
  history,
  onSelect,
}: {
  history: ThreadState[];
  onSelect: (cp: ThreadState) => void;
}) {
  return (
    <aside className="w-80 overflow-y-auto border-l bg-gray-50 p-4">
      <h2 className="mb-4 text-sm font-semibold uppercase text-gray-500">
        Checkpoint Timeline
      </h2>
      <div className="space-y-2">
        {history.map((cp, i) => {
          const nextNodes = cp.next?.join(", ") || "Complete";
          const msgCount = (cp.values?.messages as unknown[])?.length ?? 0;

          return (
            <button
              key={cp.checkpoint.checkpoint_id}
              onClick={() => onSelect(cp)}
              className="w-full rounded-lg border bg-white p-3 text-left
                         hover:border-blue-400 hover:shadow-sm transition-all"
            >
              <div className="flex items-center justify-between">
                <span className="text-xs text-gray-400">#{i + 1}</span>
                <NodeBadge name={nextNodes} />
              </div>
              <p className="mt-1 text-sm font-medium">Next: {nextNodes}</p>
              <p className="text-xs text-gray-500">
                {msgCount} message{msgCount !== 1 ? "s" : ""}
              </p>
            </button>
          );
        })}
      </div>
    </aside>
  );
}

查看检查点状态#

点击某个检查点应显示该时间点的完整状态。JSON 查看器让开发者可以完整了解智能体当时知道什么、做出了什么决定：

tsx 
function CheckpointInspector({ checkpoint }: { checkpoint: ThreadState }) {
  const [expanded, setExpanded] = useState(false);

  return (
    <div className="rounded-lg border bg-white p-4">
      <div className="flex items-center justify-between">
        <h3 className="font-semibold">
          Checkpoint {checkpoint.checkpoint.checkpoint_id?.slice(0, 8)}...
        </h3>
        <button
          onClick={() => setExpanded(!expanded)}
          className="text-sm text-blue-600 hover:underline"
        >
          {expanded ? "Collapse" : "Expand"} state
        </button>
      </div>

      <div className="mt-2 space-y-1 text-sm">
        <p>
          <strong>Next:</strong>{" "}
          {checkpoint.next?.join(", ") || "—"}
        </p>
        <p>
          <strong>Messages:</strong>{" "}
          {(checkpoint.values?.messages as unknown[])?.length ?? 0}
        </p>
      </div>

      {expanded && (
        <div className="mt-3 max-h-96 overflow-auto rounded bg-gray-900 p-3">
          <pre className="text-xs text-gray-200">
            {JSON.stringify(checkpoint.values, null, 2)}
          </pre>
        </div>
      )}
    </div>
  );
}
提示

对于生产环境的 UI，考虑使用支持折叠节点的正规 JSON 查看器组件，而不是原始的 JSON.stringify。react-json-view 或 react-json-tree 等库能为用户带来好得多的探索体验。

从检查点恢复#

时间旅行的核心是能够 从任意先前的检查点恢复执行。当用户选择一个检查点时，调用 submit 并传入 undefined 输入，同时将检查点 ID 作为 forkFrom 传入：

typescript 
const checkpointId = selectedCheckpoint.checkpoint.checkpoint_id;
if (checkpointId) {
  stream.submit(undefined, { forkFrom: checkpointId });
}

SDK 会将 undefined 或 null 输入作为 null 发送，从而从所选检查点继续执行，而不提供新的输入。空对象（{}）属于新输入，而不是相同的继续信号。如果该检查点没有后续节点，就没有待重放的工作。

新的运行会在同一线程中创建另一条路径。UI 会展示该路径；原始检查点仍保留在历史记录中。

警告

重放检查点可能会再次执行下游工具和 API 调用。它不会撤销此前的外部副作用，例如已发送的消息或数据库写入。在重放运行前请检查这些副作用。

SplitView 布局#

时间旅行最适合采用分栏布局，主聊天区在左，时间线在右：

tsx 
function TimeTravelLayout() {
  const [threadId, setThreadId] = useState<string | null>(null);
  const [history, setHistory] = useState<ThreadState[]>([]);
  const stream = useStream<typeof myAgent>({
    apiUrl: AGENT_URL,
    assistantId: "time_travel",
    threadId,
    onThreadId: setThreadId,
  });

  const [selectedCheckpoint, setSelectedCheckpoint] =
    useState<ThreadState | null>(null);

  useEffect(() => {
    if (!threadId || stream.isLoading) return;
    stream.client.threads.getHistory(threadId).then(setHistory);
  }, [stream.client, threadId, stream.isLoading]);

  return (
    <div className="flex h-screen">
      {/* Main chat area */}
      <main className="flex-1 overflow-y-auto p-6">
        <div className="mx-auto max-w-2xl space-y-4">
          {stream.messages.map((msg) => (
            <Message key={msg.id} message={msg} />
          ))}
        </div>
        <ChatInput
          onSubmit={(text) =>
            stream.submit({ messages: [{ type: "human", content: text }] })
          }
          isLoading={stream.isLoading}
        />
      </main>

      {/* Timeline sidebar */}
      <aside className="w-96 overflow-y-auto border-l bg-gray-50">
        <TimelineSidebar
          history={history}
          selected={selectedCheckpoint}
          onSelect={setSelectedCheckpoint}
          onResume={(cp) => {
            if (!cp.checkpoint.checkpoint_id) return;
            stream.submit(undefined, {
              forkFrom: cp.checkpoint.checkpoint_id,
            });
          }}
        />
        {selectedCheckpoint && (
          <CheckpointInspector checkpoint={selectedCheckpoint} />
        )}
      </aside>
    </div>
  );
}

提取检查点元数据#

将原始检查点数据转换为适合在时间线中展示的条目：

typescript 
function formatCheckpoints(history: ThreadState[]) {
  return history.map((cp, index) => ({
    index,
    id: cp.checkpoint?.checkpoint_id,
    nextLabel: cp.next?.join(", ") || "Complete",
    messageCount: (cp.values?.messages as unknown[])?.length ?? 0,
    hasInterrupts: cp.tasks?.some((t) => t.interrupts?.length) ?? false,
    nextNodes: cp.next ?? [],
  }));
}

这样可以轻松渲染带有有意义标签的时间线条目，而不是原始 ID。

使用场景#

时间旅行在许多场景中都极具价值：

  • 调试智能体行为：逐步查看智能体的决策，理解它为何选择某条特定路径

  • 尝试另一条路径：从较早的已保存状态继续，而不删除原始检查点

  • 探索替代方案：从对话中途的检查点分叉，观察不同的输入如何改变结果

  • 审计：为合规、质量保证或事后分析而审查智能体操作的完整历史

  • 教学：逐步讲解智能体的执行过程，说明多步推理如何运作

注意

时间旅行与 人在回路 模式结合时尤其强大。如果人工审核者在中断点拒绝了智能体的某个操作，可以从该操作执行前的检查点恢复，并提供纠正性输入。

在时间线中处理中断#

包含中断（人在回路暂停）的检查点值得特别的视觉处理。它们代表智能体停下并等待人工输入的时刻：

tsx 
function TimelineEntry({
  checkpoint,
  index,
}: {
  checkpoint: ThreadState;
  index: number;
}) {
  const hasInterrupt = checkpoint.tasks?.some(
    (t) => t.interrupts && t.interrupts.length > 0
  );

  return (
    <div
      className={`rounded-lg border p-3 ${
        hasInterrupt
          ? "border-amber-300 bg-amber-50"
          : "border-gray-200 bg-white"
      }`}
    >
      <div className="flex items-center gap-2">
        <span className="text-xs text-gray-400">#{index + 1}</span>
        {hasInterrupt && (
          <span className="rounded bg-amber-200 px-1.5 py-0.5 text-xs font-medium text-amber-800">
            Interrupt
          </span>
        )}
      </div>
      <p className="mt-1 text-sm font-medium">
        Next: {checkpoint.next?.join(", ") || "Complete"}
      </p>
    </div>
  );
}

最佳实践#

  • 延迟加载历史：对于有数百个检查点的线程，应分页或只加载最近的 N 条，以保持 UI 响应流畅。

  • 显示有意义的标签：展示已调度的后续节点和消息数量，而不是原始检查点 ID。用户需要的是上下文，不是 UUID。

  • 恢复前确认：在开始另一条路径前显示确认对话框，尤其是当下游节点会产生外部副作用时。

  • 高亮当前检查点：以视觉方式明确哪个检查点对应对话的当前状态。

  • 支持键盘导航：高级用户会希望用方向键逐步浏览检查点。为时间线添加键盘处理程序，以获得流畅的调试体验。

  • 对比检查点之间的状态差异：对于高级用户，展示两个相邻检查点之间的变化可以精确揭示智能体状态在每一步如何演变。
