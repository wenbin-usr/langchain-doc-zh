MCP 认证

在 LangChain 中使用 bearer token、OAuth 2.1 或按用户凭据对 MCP 连接进行身份验证。
约 4 分钟 社区翻译 查看英文原文 ↗

大多数远程 MCP 服务器都需要身份验证。MCPAdapter 将认证交给 FastMCP 处理，因此 fastmcp.Client 接受的任何凭据都可用：静态的 bearer token、完整的 OAuth 2.1 流程，或任意 httpx.Auth。在预构建客户端上传入凭据，再把该客户端交给适配器。当一个智能体与多个服务器通信时，使用 按服务器认证；在部署环境中，使用 按用户认证，使每次运行都以调用者的身份访问服务器。

注意

langchain.mcp 命名空间要求 langchain[mcp]>=1.4.0，且处于 beta 阶段。API 可能发生变化。

Bearer token#

最简单的情况：服务器校验你预先配置的令牌，并将其添加到 Authorization: Bearer <token> 请求头中。没有发现流程、浏览器或刷新。把令牌作为客户端的 auth 传入：

python 
from fastmcp.client import Client
from langchain.mcp import MCPAdapter


async def load_tools_with_bearer(url: str, token: str) -> list:
    # `auth` accepts a bearer-token string, the literal "oauth" (full OAuth 2.1
    # with dynamic client registration), or any `httpx.Auth`.
    async with MCPAdapter(Client(url, auth=token)) as adapter:
        return await adapter.list_tools()

auth 参数接受 bearer token 字符串、字面量 "oauth"，或任意 httpx.Auth。在 MCPConfig 集群中，每个服务器都使用同一个键。

OAuth 认证#

对于自行签发凭据的服务器，传入字面量字符串 "oauth"。FastMCP 会执行完整的 OAuth 2.1 流程：发现、动态客户端注册、浏览器重定向以及令牌交换。动态客户端注册意味着客户端在运行时自行注册，而无需你预先配置客户端 ID：

python 
async def load_tools_with_oauth(url: str) -> list:
    # "oauth" runs discovery, dynamic client registration, the browser redirect,
    # and the token exchange. Pass `OAuth(..., token_storage=...)` to persist
    # tokens across runs instead of repeating the browser step each time.
    async with MCPAdapter(Client(url, auth="oauth")) as adapter:
        return await adapter.list_tools()

默认情况下令牌保存在内存中，因此每次运行都会重复浏览器步骤。传入带有令牌存储的预构建 OAuth provider，即可跨运行持久化令牌：

python 
from fastmcp.client import Client
from fastmcp.client.auth import OAuth

oauth = OAuth(mcp_url="https://example.com/mcp", token_storage=...)
client = Client("https://example.com/mcp", auth=oauth)

FastMCP 为常见身份提供方（Auth0、WorkOS、Okta 等）提供了 provider；客户端执行的流程在这些提供方之间完全相同。参见 FastMCP 文档中的 OAuth 认证。

按服务器认证#

当一个智能体与多个服务器通信时，每个服务器可能需要各自的凭据。用 ClientGroup 为每个服务器建立独立连接，并为每个客户端分别设置 auth，使每台服务器独立完成认证：

python 
from fastmcp.client.group import ClientGroup


async def load_with_per_server_auth(
    billing_url: str, docs_token: str, docs_url: str
) -> list:
    # Each server carries its own credential. A `ClientGroup` keeps one
    # connection per server, so each authenticates independently.
    group = ClientGroup(
        {
            "billing": Client(billing_url, auth="oauth"),
            "docs": Client(docs_url, auth=docs_token),
        }
    )
    async with MCPAdapter(group) as adapter:
        return await adapter.list_tools()

按用户认证#

在部署环境中，每次运行都应以发起该运行的用户身份访问 MCP 服务器，而不是使用同一份共享凭据。该模式包含两部分：

  1. 在 LangGraph 服务器上对调用者进行身份验证。由 自定义认证处理器 将传入请求解析为用户身份，每次运行都从自身的运行时读取该身份。

  2. 为该用户签发或换取凭据。在 图工厂 中，读取用户身份并用按用户令牌构建 MCP 客户端，使该连接携带该用户的授权。

python 
from fastmcp.client import Client
from fastmcp.client.auth import BearerAuth

CONFIG = {
    "mcpServers": {
        "docs": { "url": "https://example.com/mcp" }
    }
}

async def make_graph(runtime):
    user = runtime.user.identity if runtime.user is not None else "anonymous"
    auth = BearerAuth(token_for(user))  # exchange for a per-user token
    async with MCPAdapter(Client(CONFIG, auth=auth)) as adapter:
        tools = await adapter.list_tools()
        return create_agent("claude-sonnet-5", tools)

在生产环境中，token_for 代表部署中已有的任意机制：将会话换取按用户令牌的 OAuth 网关，或按身份执行授权码流程的 fastmcp.client.auth provider。以验证后的身份作为键，按用户隔离所有 缓存的响应，确保一个用户永远不会看到另一个用户缓存的工具列表。
