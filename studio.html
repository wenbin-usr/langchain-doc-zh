LangChain/智能体开发/LangSmith Studio

LangSmith Studio

在本地使用 LangChain 构建智能体时，可视化地了解智能体内部正在发生什么、与之实时交互，并在问题出现时进行调试会很有帮助。LangSmith Studio 是一个免费的可视化界面，用于在本地机器上开发和测试你的 LangChain 智能体。
约 5 分钟 社区翻译 查看英文原文 ↗

Studio 会连接到你本地运行的智能体，向你展示智能体执行的每一步：发送给模型的提示词、工具调用及其结果，以及最终输出。你可以测试不同的输入、检查中间状态，并在无需额外代码或部署的情况下迭代智能体的行为。

本页介绍如何为本地 LangChain 智能体设置 Studio。

前置条件#

开始之前，请确保你已具备以下条件：

  • 一个 LangSmith 账户：在 smith.langchain.com 免费注册或登录。

  • LangSmith API 密钥：按照 创建 API 密钥 指南操作。

  • 如果你不希望数据被 追踪 到 LangSmith，请在智能体的 .env 文件中设置 LANGSMITH_TRACING=false。禁用追踪后，不会有任何数据离开你的本地服务器。

设置本地智能体服务器#

1. 安装 LangGraph CLI#

LangGraph CLI 提供了一个本地开发服务器（也称为 Agent Server），用于将你的智能体连接到 Studio。

# Python >= 3.11 is required.
pip install -U "langgraph-cli[inmem]"
# Python >= 3.11 is required.
uv add "langgraph-cli[inmem]"

2. 准备你的智能体#

如果你已经有 LangChain 智能体，可以直接使用。本示例使用一个简单的电子邮件智能体：

title="agent.py" 
from langchain.agents import create_agent

def send_email(to: str, subject: str, body: str):
    """Send an email"""
    email = {
        "to": to,
        "subject": subject,
        "body": body
    }
    # ... email sending logic

    return f"Email sent to {to}"

agent = create_agent(
    "gpt-5.5",
    tools=[send_email],
    system_prompt="You are an email assistant. Always use the send_email tool.",
)

3. 环境变量#

注意

在基于 智能体的工作区 中，发送追踪数据前需先 创建智能体 一次。使用 智能体寻址 选择其标识符和环境。如果某个集成需要 project_name，请使用所选环境的 tracer_session_name 作为兼容性值。

Studio 需要一个 LangSmith API 密钥来连接你的本地智能体。在项目根目录创建一个 .env 文件，并添加来自 LangSmith 的 API 密钥。

警告

确保你的 .env 文件没有被提交到版本控制系统，例如 Git。

.env 
LANGSMITH_API_KEY=lsv2...
LANGSMITH_AGENT_ID="<your-agent-id>"
LANGSMITH_AGENT_ENVIRONMENT="local"

4. 创建 LangGraph 配置文件#

LangGraph CLI 使用配置文件来定位你的智能体并管理依赖。在应用目录中创建一个 langgraph.json 文件：

title="langgraph.json" 
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent.py:agent"
  },
  "env": ".env"
}

create_agent 函数会自动返回编译后的 LangGraph 图，这正是配置文件中 graphs 键所期望的内容。

注意

有关配置文件 JSON 对象中每个键的详细说明，请参阅 LangGraph 配置文件参考。

此时，项目结构如下所示：

bash 
my-app/
├── src
│   └── agent.py
├── .env
└── langgraph.json

5. 安装依赖#

从根目录安装项目依赖：

pip install langchain langchain-openai
uv add langchain langchain-openai

6. 在 Studio 中查看你的智能体#

启动开发服务器，将你的智能体连接到 Studio：

bash 
langgraph dev
警告

Safari 会阻止 localhost 与 Studio 的连接。要绕过此限制，请在运行上述命令时加上 --tunnel，以便通过安全隧道访问 Studio。

服务器启动后，你的智能体既可以通过 http://127.0.0.1:2024 的 API 访问，也可以通过 https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024 的 Studio UI 访问：

在 Studio 连接到本地智能体后，你可以快速迭代智能体的行为。运行一次测试输入，检查完整的执行追踪，包括提示词、工具参数、返回值以及 token/延迟指标。当出现问题时，Studio 会捕获异常及其周边状态，帮助你了解发生了什么。

开发服务器支持热重载——在代码中修改提示词或工具签名，Studio 会立即反映这些更改。你可以从任意步骤重新运行对话线程，无需从头开始即可测试更改。该工作流既适用于简单的单工具智能体，也适用于复杂的多节点图。

有关如何运行 Studio 的更多信息，请参阅 LangSmith 文档 中的以下指南：

  • 管理线程

  • 迭代提示词

  • 调试 LangSmith 追踪

  • 将节点添加到数据集
