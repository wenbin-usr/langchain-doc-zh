前端概览

借助 LangChain 智能体的实时流式传输构建生成式 UI
约 6 分钟 社区翻译 查看英文原文 ↗

为使用 createAgent 创建的智能体构建丰富、可交互的前端。这些模式涵盖从基础的消息渲染到人在回路审批、排队提交、持久化流重新加入以及时间旅行调试等高级工作流。

LangChain 前端 SDK 面向智能体应用而构建，而不只是处理 token 流式传输的聊天机器人。渲染消息的同一个 hook 还会暴露智能体的持久化线程状态、工具调用生命周期、中断、检查点历史以及自定义状态值，因此你的 UI 可以成为长时间运行的智能体工作的控制面板。

注意

这些模式使用 v1 前端 SDK 包。如果你使用的是更早的版本，请参阅 React、Vue、Svelte 和 Angular 的迁移指南。

架构#

每个模式都遵循相同的架构：createAgent 后端通过 SDK 的流式 API 将状态流式传输到前端。

在后端，createAgent 会生成一个编译后的 LangGraph 图，该图暴露流式 API。在前端，流句柄连接到该 API 并提供响应式状态——消息、工具调用、中断、值以及线程元数据——你可以用任意框架渲染这些状态。

为什么使用 LangChain 前端 SDK？#

大多数 AI UI 库只帮助你向聊天记录中追加流式传输的文本。LangChain 的 SDK 则暴露生产环境智能体所需的更丰富的运行时语义：

能力在 UI 中可实现的功能
持久化线程刷新页面、切换设备或重新加入运行，而不会丢失对话状态。
类型化智能体状态渲染任意状态键，而不只是消息：待办事项、流水线输出、引用、沙箱文件、指标或自定义业务对象。
工具调用生命周期将待处理、已完成和失败的工具调用展示为专用 UI 卡片，而不是原始 JSON。
中断为人工审批、编辑或缺失信息暂停执行，然后从智能体停止的确切位置恢复。
检查点基于持久化的状态快照构建编辑、重试、分支、审计和时间旅行流程。
嵌套执行可视化深度智能体、子智能体和图节点，而不必将所有内容压平成一个难以阅读的流。
框架原生响应式在 React、Vue、Svelte 或 Angular 中使用同一套协议，同时保留各自惯用的 hook、组合式函数、store 或 signal。

这些基础能力让你能够设计出这样的 UI：用户可以在智能体工作进行的当下查看、引导、暂停、恢复和分叉该工作。

agent.py 
from langchain.agents import create_agent
from langgraph.checkpoint.memory import MemorySaver

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather, search_web],
    checkpointer=MemorySaver(),
)
types.ts 
export interface GraphState {
  messages: BaseMessage[];
}
Chat.tsx 
import { useStream } from "@langchain/react";
import type { GraphState } from "./types";

function Chat() {
  const stream = useStream<GraphState>({
    apiUrl: "http://localhost:2024",
    assistantId: "agent",
  });

  return (
    <div>
      {stream.messages.map((msg) => (
        <Message key={msg.id} message={msg} />
      ))}
    </div>
  );
}

React、Vue 和 Svelte 使用 useStream。Angular 使用 injectStream：

typescript 
import { useStream } from "@langchain/react";      // React
import { useStream } from "@langchain/vue";        // Vue
import { useStream } from "@langchain/svelte";     // Svelte
import { injectStream } from "@langchain/angular"; // Angular

类型推断#

向 useStream（在 Angular 中为 injectStream）传入类型参数，即可类型安全地访问 stream.messages、stream.toolCalls、stream.interrupt、stream.values 及其他响应式状态。

定义一个与智能体状态 schema 匹配的 TypeScript 接口，并将其作为类型参数传入：

typescript 
import type { BaseMessage } from "langchain";

interface AgentState {
  messages: BaseMessage[];
}

const stream = useStream<AgentState>({
  apiUrl: "http://localhost:2024",
  assistantId: "agent",
});

将 langgraph.json 中的图名称用作 assistantId。在本指南各处的模式示例中，请将 typeof myAgent 替换为你的接口名（例如 AgentState）。

如果你的智能体暴露了自定义状态键，请扩展该接口：

typescript 
import type { BaseMessage, Todo } from "langchain";

interface AgentState {
  messages: BaseMessage[];
  todos: Todo[];
}

模式#

渲染消息与输出#

Markdown 消息

解析并渲染流式传输的 Markdown，提供正确的格式和代码高亮。

结构化输出

将类型化的智能体响应渲染为自定义 UI 组件，而不是纯文本。

推理 token

在可折叠块中展示模型的思考过程。

生成式 UI

渲染智能体生成的界面，覆盖从受控到声明式再到开放式的整个谱系。

展示智能体操作#

工具调用

将工具调用展示为内容丰富、类型安全的 UI 卡片，并带有加载和错误状态。

无头工具

在客户端运行浏览器和设备 API，同时在智能体一侧保留类型化的工具 schema。

人在回路

通过批准、拒绝和编辑工作流暂停智能体以进行人工审核。

管理对话#

分支式聊天

编辑消息、重新生成响应并浏览对话分支。

消息队列

在智能体按顺序处理消息的同时排队多条消息。

高级流式传输#

加入与重新加入流

断开并重新连接到正在运行的智能体流，而不会丢失进度。

时间旅行

查看并浏览对话历史中的任意检查点，并从该检查点恢复。

集成#

流式 API 与 UI 无关，可与任意组件库或生成式 UI 框架配合使用。组件库可以负责表现层，而由其下的 LangChain SDK 负责智能体运行时状态、可恢复性、中断和检查点语义。

AI Elements

用于 AI 聊天的可组合 shadcn/ui 组件：Conversation、Message、Tool、Reasoning。

assistant-ui

无头 React 框架，内置线程管理、分支和附件支持。

OpenUI

生成式 UI 库，使用 openui-lang 组件 DSL 构建数据丰富的报告和仪表板。
