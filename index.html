LangChain 概览

LangChain 提供 create_agent：一个极简、高度可配置的智能体运行框架。你可以用模型、工具、提示词和中间件，精确组合出符合自身用例需求的智能体。
约 4 分钟 社区翻译 查看英文原文 ↗

智能体 = 模型 + 运行框架。LangChain 提供 create_agent：一个极简、高度可配置的运行框架。运行框架是模型循环之外的一切：提示词、工具，以及任何塑造行为的中间件。从这些基础原语入手，精确组合你的用例所需的内容。支持 OpenAI、Anthropic、Google 等。

提示

LangChain、LangGraph 与 Deep Agents 的区别

如果你希望在运行生产智能体时无需自行管理基础设施，可以从 Managed Deep Agents 开始，它提供开箱即用的运行框架（上下文压缩、虚拟文件系统、子智能体）。如果你希望在使用同一 Deep Agents 运行框架的同时获得最大灵活性，也可以使用 Deep Agents SDK 自行托管智能体，或运行自定义的 LangSmith Deployment。Deep Agents 构建于 LangChain 智能体 之上，你也可以直接使用后者。

使用 LangChain（create_agent）获得高度可定制的运行框架，轻松适配你的用例和数据。

使用 LangGraph 这一底层编排框架，应对将确定性工作流与智能体工作流相结合的高级需求。

使用 LangSmith 追踪、调试和评估用上述任一框架构建的智能体。按照 追踪快速入门 完成设置。我们还建议你配置 LangSmith Engine，它会监控你的追踪记录、发现问题并提出修复建议。

创建智能体#

以下示例演示如何使用自定义工具创建一个简单的 LangChain 智能体：

# pip install -qU langchain "langchain[openai]"
from langchain.agents import create_agent

def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
)
print(result["messages"][-1].content_blocks)

提示

使用 LangSmith 追踪请求、调试智能体行为并评估输出。设置 LANGSMITH_TRACING=true 和你的 API 密钥即可开始。

核心优势#

统一的模型接口

用同一套接口访问各提供商的聊天模型、嵌入模型等。只需极少的代码改动即可切换模型，让应用在需求变化时保持可移植性。

高度可配置的运行框架

以 create_agent 作为最小运行框架起步，通过中间件逐步添加能力。只组合你的用例所需的部分，从护栏和重试，到路由和自定义工具策略。

构建于 LangGraph 之上

LangChain 的智能体构建在 LangGraph 之上，这使我们能够利用 LangGraph 的持久执行、人在回路支持、状态持久化等能力。

使用 LangSmith 调试

在一处查看追踪记录、工具调用、状态转换和延迟。借助执行数据定位失败模式、评估质量并改进智能体行为。
